
#  Air Quality Prediction System

# Overview
This project predicts Air Quality Index (AQI) using IoT sensors and Machine Learning.

# Features
- AQI prediction using Random Forest
- Health risk classification
- Interactive Streamlit dashboard
- Sensor-based feature selection

# Tech Stack
- Python
- Scikit-learn
- Streamlit
- IoT Sensors (MQ135, MQ7, PMS5003)

# Model Performance
- R² Score: 0.92

# Run Project
streamlit run app/app.py
